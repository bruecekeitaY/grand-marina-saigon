# インデックス申請の手順（手動）

Claude のブラウザ操作が不安定なとき用。1件あたり約30秒。

## 手順

1. GSC を開く
   https://search.google.com/search-console?resource_id=https%3A%2F%2Fgrand-marina-saigon.com%2F
2. 画面上部の「URL 検査」ボックスに URL を貼り付けて Enter
3. 結果を見て分岐する
   - **「URL が Google に登録されていません」** → 右下の
     **「インデックス登録をリクエスト」** をクリック → 完了
   - **「URL は Google に登録されています」** → 何もせず次へ（申請すると枠の無駄）
4. 1日の上限に達すると
   **「割り当て量の超過 — プロパティの URL 検査の割り当て量を超えています」**
   が出る。ここまで来たらその日は終了。翌日リセットされる。

## 注意

「インデックス登録をリクエスト」を押した直後に出る
**「割り当て量を超えています」は誤表示のことが多い。**
画面を開き直して同じ URL でやり直すと普通に通るので、1回で諦めないこと。
本物の上限は手順4のメッセージ（画面を再読込しても消えない）。
